# Sistema de Manutenção

Esse é um projeto desenvolvido para facilitar o gerenciamento de Manutenções do SENAI.

## 🔧 Tecnologias Utilizadas

* **PHP** – processamento do backend
* **MySQL** – armazenamento e consulta dos dados
* **HTML5** – estrutura das páginas
* **CSS3** – estilização da interface
* **JavaScript** – interações e dinamismo
